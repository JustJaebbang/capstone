1. 영화 목록 API (GET /dashboard/movies)
   - /movies 화면의 영화 카드를 채울 데이터
   - 영화별로: 포스터 이미지 URL, 장르, 감성 비율, TOP 키워드, 리뷰 수
   - 특히 포스터 URL 꼭 넣어줘 (지금은 포스터 URL이 없음)

2. 대시보드 통계 API (GET /dashboard/summary)
   - "최근 분석된 영화" 공지 배너에 쓸 데이터
   - 최근 분석 활동 목록 (영화 제목, 완료 시각 등)

3. 영화 요소별 점수 (final-result API에 추가)
   - 결과 화면에 막대그래프로 영화 요소 점수 보여주려고 해
   - 요소: 스토리/연기/몰입감/전개/재미/연출 (6개), 각각 0~100 점수
   - 협의하고 싶은 거:
     · 요소 6개 고정(스토리/연기/몰입감/전개/재미/연출)
     · 요소 언급 리뷰의 긍정/부정 비율
